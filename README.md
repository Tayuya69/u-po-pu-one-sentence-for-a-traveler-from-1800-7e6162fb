Entry for the [make.fun bounty "One Sentence for a Traveler from 1800"](https://make.fun/competitions/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb): one sentence that would leave a traveler from 1800 with the truest and clearest picture of the modern internet, built only from things a person from 1800 already knows — a road, a post office, a library.

> Imagine every library, post office, and market square in the world joined by one road, where any letter arrives in a blink and anyone may speak.

`main.ts` deterministically writes that single sentence (144 characters, no trailing newline) to `/output/entry.txt`.
